# zennotes_noctilia_theme

## ABOUT
Allows Zennotes color to change and match the current Noctilia color theme. These files were generated with Claude Code.

## STEPS
In order to make the Niri Noctilia theme working you need to do the following:

1. Copy the noctilia.css theme file into the overrides folder under ~/.config/zennotes/overrides

2. Copy the zennotes.css to the ~/.config/noctilia/templates/.

3. Copy the templates.toml to ~/.config/noctilia/.

4. Either log out and log in or reboot and the theme should take effect.
